# 共享麦田：两组AI实验

演示目标：观察个人决策如何影响公共资源，比较兼顾未来粮源的普通性格与偏向当期个人收益的激进性格。

两组都从48株成熟小麦、四人各1份库存开始。每回合各自选择收割0～3株，剩余麦株按四分之一恢复并向下取整，不超过48株，再各自消耗1份口粮。没有治理、共同规则或补种操作介入。

普通与激进改变四名角色的性格和系统提示，程序的分配、恢复和口粮规则完全相同。收割量由模型返回，性格模式不在结算时强制覆盖。四名角色共享一次请求的上下文，不是四个隔离运行的智能体。

切换实验会重置相同初始资源和近期记忆，暂停自动。保留API配置、历史记录和累计请求数，便于分别运行、按实验编号比较。

界面重点显示成熟株数、每人库存、缺粮和决策理由。公共资源耗尽时私人库存可能仍高，缺粮会延后出现。

所有完成的回合必须来自完整、合法的四人AI决策。API未配置、请求失败、输出不完整或请求额度用尽时，不提交回合并关闭自动运行，资源、口粮、记忆和回合数保持原值。暂停原因显示在面板和服务器日志，并写入事件记录；回合历史、JSONL和CSV只追加已完成的AI回合。修正API配置后重载，手动推进或重新开启自动即可继续，无需重置实验。

最短演示：普通AI运行若干轮，重置后激进AI运行若干轮，比较麦田疏密与私人储粮。模型实际是否克制或竞争以真实输出为准。特定行为的数值对照由测试验证，不写成剧情。

恢复公式是教学模型，不用于证明真实农业规律或经济定律。重复实验、固定模型及参数、保持相同初始条件，才能较可靠地比较角色动机对结果的影响。
